# Job Study Path

A phone-friendly study path for the 30-day job plan: 26 lessons across algorithms, backend, system design, applied AI and tooling.

Each lesson has:

- **Learn**: summary, explanation, worked example and a YouTube search.
- **Reads**: posts from the web with a 1–5 quality rating and a short take on the concept.
- **Practice**: 8–10 questions of mixed types (multiple choice, true/false, select all, put in order, fill the gap, type the answer, match pairs, type a number, tap the line). Three hearts per session.

Files: `index.html` (app), `lessons.js` (all content). Open `index.html` in a browser, or use the GitHub Pages site.
